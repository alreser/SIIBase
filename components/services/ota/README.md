# services/ota/

Reservado para un futuro servicio de actualización OTA (esp_https_ota).
No forma parte del alcance actual del template — requiere además ajustar
`partitions.csv` (agregar particiones `ota_0`/`ota_1`/`otadata`).

Si tu TP lo necesita, este es el lugar donde agregar el componente,
siguiendo la misma convención que el resto de `services/`.
